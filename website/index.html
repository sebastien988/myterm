Featured project

myterm

Native Windows terminal emulator · Rust

A real windowed terminal emulator — not a console wrapper — built with egui/eframe for rendering and egui_term (backed by alacritty_terminal) for PTY management and VT/ANSI parsing.

  • Tabs with independent shell sessions, each with its own PTY
  • Keyboard-first: Ctrl+Shift+T new tab, Ctrl+Tab cycle
  • Dark theme, rounded pill tabs and a purple accent on the active tab
  • Window title mirrors the active tab's shell title
